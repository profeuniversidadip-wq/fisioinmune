# FisioInmune IA — revisión integral

Versión revisada del banco de preguntas de Sistema Inmune.

- 80 preguntas: 20 por nivel.
- Nivel 1: Define / Identifica.
- Nivel 2: Interpreta.
- Nivel 3: Relaciona.
- Nivel 4: Integración y casos simples.
- Distractores plausibles y del mismo dominio conceptual.
- Se evitaron alternativas absurdas, pistas evidentes y redacciones artificiales.
- 10 preguntas por sesión.
- 2 intentos.
- Alternativas reordenadas también en el segundo intento.
- Retroalimentación específica según el distractor seleccionado.
